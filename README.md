# 🔮 Oráculo Interativo

Um oráculo interativo que responde a perguntas dos utilizadores com sabedoria mística e respostas aleatórias.

## 🎯 Funcionalidades

- ✨ Interface intuitiva e imersiva
- 🎲 Respostas aleatórias e variadas
- 💫 Efeitos visuais e animações
- 📱 Responsivo (mobile, tablet, desktop)
- 🎨 Design temático (tema místico/oculto)

## 🚀 Tecnologia

- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting:** GitHub Pages

## 📁 Estrutura

```
oraculo/
├── index.html          # Página principal
├── css/
│   └── style.css       # Estilos
├── js/
│   └── script.js       # Lógica do oráculo
└── assets/
    └── images/         # Imagens e ícones
```

## ⚙️ Como Usar

1. Clone o repositório
2. Abra `index.html` no browser
3. Faça uma pergunta ao oráculo e espere pela resposta
