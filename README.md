# 🔮 A Voz da Alma — Oráculo de Maria Madalena

Um oráculo digital interativo e místico com 37 cartas inspiradas na sabedoria de Maria Madalena.

## ✨ Características

- **37 Cartas Completas**: Cada carta contém:
  - Mensagem Essencial
  - A Voz de Maria Madalena
  - Ritual de Integração
  - Reflexão para Diário da Alma
  - Palavra-chave e Energia

- **3 Tipos de Tiradas**:
  - 🔮 **Carta do Dia** — Uma única carta para orientação diária
  - 🔮 **Tiragem 3 Cartas** — Passado, Presente, Futuro
  - 🔮 **Tiragem 5 Cartas** — Leitura mais aprofundada

- **Design Elegante**: Interface em tons creme/rosa com tipografia Georgia, inspirada em livros místicos

- **Interatividade**: Clique no baralho ou nas cartas para revelar respostas

- **Responsivo**: Funciona perfeitamente em desktop, tablet e mobile

## 🚀 Como Usar

1. **Escolhe uma Tirada**: Clica em "Carta do Dia", "Tiragem 3 Cartas" ou "Tiragem 5 Cartas"
2. **Clique no Baralho**: Clica na esfera 🔮 para revelar as cartas uma a uma
3. **Explora a Carta**: Clica em qualquer carta revelada para ver seus detalhes completos
4. **Nova Consulta**: Usa o botão "Nova Consulta" para recomeçar
